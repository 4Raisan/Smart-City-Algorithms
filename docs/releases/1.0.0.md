# Smart City Algorithms 1.0.0

First packaged release of the CCS2300 Data Structures and Algorithms coursework.

- Route planner: manage locations and roads with an adjacency-list graph, a location BST and BFS traversal.
- Data sorter: compare Bubble, Merge and Quick Sort using random or manually entered integers.
- Performance analyzer: demonstrate Linear/Binary Search and sorting timings at 100, 500 and 1,000 elements.
- Includes input validation, the usage walkthrough and module architecture documentation.

## Downloads

- `Smart-City-Algorithms-1.0.0.jar`: ready-to-run console application, compiled for Java 8 compatibility. Requires Java 8 or newer; no external libraries are needed.
- `Smart-City-Algorithms-1.0.0-source.zip`: complete tracked project source and documentation. Requires JDK 8 or newer to compile.
- `SHA256SUMS.txt`: SHA256 hashes for both downloads.

Run the downloaded application from a terminal:

```sh
java -jar Smart-City-Algorithms-1.0.0.jar
```

Locations and roads remain in memory for the current session. BFS is a traversal demonstration, not a shortest-route calculation. Timings are single-run educational measurements and vary with the JVM and input; they are not rigorous benchmarks.
